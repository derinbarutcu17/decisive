# Code of Conduct

Decisive is a small open-source project. We want its issues, pull requests, discussions, and other project spaces to be welcoming, constructive, and safe for everyone.

This code of conduct is adapted from the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standards

Examples of behavior that contributes to a positive environment include:

- showing empathy, patience, and respect;
- assuming good faith while asking for evidence and clarification;
- giving and receiving constructive feedback;
- acknowledging different experience levels, cultures, and perspectives; and
- focusing criticism on ideas, decisions, and behavior rather than people.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, doxxing, sexualized language or attention, trolling, sustained disruption, and publishing someone else's private information without permission. Deliberately submitting malicious code, private data, or exploit details in a public project space is also not acceptable.

## Scope

This code of conduct applies in repository issues, pull requests, discussions, reviews, project-managed communication channels, and any setting where someone is representing the Decisive project.

## Reporting and enforcement

If you experience or witness unacceptable behavior, report it privately to the repository maintainer through a private contact method listed on [the maintainer's GitHub profile](https://github.com/derinbarutcu17). Please include links, dates, and a concise description, and preserve relevant evidence when it is safe to do so.

If no private contact method is available, open an issue titled `Private conduct contact` without incident details and ask the maintainer to provide a private channel. Do not use the security-advisory channel for conduct reports unless the report also contains a security vulnerability.

Reports will be handled as confidentially as practical. The maintainer may remove or edit harmful content, ask participants to stop or revise behavior, close discussions, restrict participation, or take other actions needed to protect the project community. Retaliation against a person who reports a concern in good faith is not acceptable.
